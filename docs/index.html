别问古人该怎么做，
先看古人面对的是什么。

把你现在的处境说出来，这个库会从《资治通鉴》《史记》《左传》的 6,707 个抉择事件里，找出结构相同的案例：当时有哪几个方案并列、 当事人选了哪个、后来怎样、代价记在谁头上。

用日常说法就行，不必写成书面语。输入满 4 个字会自动开始检索。

一次检索给出四样东西

不是「古人这么做所以你也这么做」。是把一个抉择现场拆开， 让你看清当时真实存在的选项和代价。剩下的判断仍然归你。

定位内核

把现代处境映射到 13 个决策内核之一，并给出这个内核真正在问的问题。命中词会一并列出，你可以自己核对它为什么这么判。

并列选项

从原文里抽出当时真实存在的方案，而不是事后总结的正确路线。进退出处这一类，平均能抽出 4.13 个并列选项。

判定结果

依原文可见的决断信号（「不听」「从之」「不许」）判定采纳与否。原文没写结果的，明确标注未载，不替古人补写。

代价分层

显性代价附原句供你自行判断归属；隐性代价标出触发词（如「畔」暗示关系转为长期对立），词在原文里，判断是我的，分得开。

13 个决策内核

每个内核对应一类反复出现的人类处境。检索时先判内核，再在内核内部比案例， 否则「像」就只是措辞上的像。

现在走是明智还是逃逸？窗口期是否已经打开？
传承择嗣 successor

谏诤抉择 remonstrate

用人察奸 employ-person

  • 引用保真 84/84（100%）　抽样正文与源文件做指纹比对，逐字命中，没有一条是改写或生成。
  • 场景识别 50/51（98.0%）　对自拟的 51 条标注问句。这是自拟标注，不是独立人工验证，请按 98% 打折扣地看。

怎么用

网站是它的演示面。真正的用法是在你自己的 Agent 里调用，让它在对话中检索。

# 按处境检索（CLI） python tuiliyan.py "该不该离开现在的单位" --top 3 # 未命中的说法可以换一种 或 直接用内核指定 python tuiliyan.py --scene remonstrate # 看全部内核 python tuiliyan.py --list-scenes

技能目录：~/AppData/Local/hermes/skills/wengu/
语料路径可用环境变量 $WENGU_CORPUS 覆盖。

把结论当信息，不当答案

这些案例是判断的材料。它不知道你的行业、你的家庭、你手上真实的牌。

注意幸存者偏差

能写进史书的，是抉择者中的极少数。同样处境下沉默转身的多数，史书不载。

古今约束强度不同

古人的「去」常意味着失去一切庇护且不可逆，你的多数损失是可修复的。类比可用，等强度套用会失真。

真正该问的那句

这些古人面对的约束里，哪一条与我最像，哪一条已经彻底消失。已消失的那条，往往正是可以放手一搏的地方。
