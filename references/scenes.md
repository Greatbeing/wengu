# 决策内核表（13 个）

用户说现代处境 → 匹配内核 → 检索该内核下的历史案例。
机器可读版本在 `scripts/scenes.py`（`SCENES` / `STEMS` / `EXTRA_STEMS` / `WEAK_STEMS`）。

| id | 名称 | 核心问题 | 隐性代价考察方向 |
|---|---|---|---|
| choose-side | 站队择主 | 该把未来押在谁身上？ | 人身依附、沉默成本、主败连带清算 |
| stay-or-go | 进退出处 | 现在走是明智还是逃逸？窗口开了吗？ | 未变现功劳、身份落差、再入场门槛 |
| successor | 传承择嗣 | 接棒者哪一项是不可让渡的底线？ | 被废者反噬、年幼者失控、合法性争议 |
| remonstrate | 谏诤抉择 | 怎么说、说几次、说到哪一层？ | 触怒当权者、失去信任、连带家族 |
| war-or-peace | 战和决断 | 必须打，还是可以绕开？真实赔率？ | 国力透支、盟友背弃、不胜的连锁反应 |
| employ-person | 用人察奸 | 可信度是验证过的，还是一厢情愿？ | 授权失控、情报倒灌、自证陷阱 |

## 匹配机制（三层）

1. **完整词**（权重 3.0）— 词典级匹配，如「辞职」「接班人」
2. **强碎片**（权重 1.0）— 多字语义碎片，如「离开」「反对」「吃力」
3. **弱碎片**（权重 0.35）— 高频功能词，如「现在」「钱」「领导」
   - 弱碎片存在的理由：不能因为句子里有个「现在」，就把
     「要不要离开公司去创业」判成「时机取舍」
4. **单字碎片**（权重 0.4）— 仅当无更强信号时计入

排序：分数降序 → 命中数降序 → id（确定性）。
主场景得分会归一化为权重，主导案例排序。

## 候选预筛：泛词降级（`CANDIDATE_DF_MAX = 0.20`）

匹配机制的产出分两层：**候选层**（谁可能相关）与**打分层**（谁排前面）。
`classical` 词表原先同时服务两层，于是单字泛词（得/度/及/时/家/门/攻/战…）
在预筛层形同虚设 —— 一个词就能捞进全库 1/5 以上事件，
`risk-return` 曾召回 **81.5%**、`timing` **81.6%**。

现在：**df/N ≥ 20% 的古典词只计分、不入选**。词表不变、打分公式不变，
只改「谁能进候选」。实测（`scripts/simulate_demotion.py`，51 条评测问法逐条对照）：

| 阈值 | 池规模收缩 | top-1 变化 | top-5 变化 | C4 |
|---|---|---|---|---|
| 10% | 53% | 0 | **7** ← 开始丢真结果 | 100% |
| **20%** | **32%** | **0** | **0** | **100%** |
| 25% | 24% | 0 | 0 | 100% |

结论：这些事件本来就因 IDF 加权排不进前列，泛词在预筛层是**纯无效载荷**。
取 20%，两侧各留 5 个百分点余量。

生效后的召回率（`python audit_skill.py` 的 D 段会打印）：

```
risk-return 49.2%   faith-or-interest 48.7%   war-or-peace 46.0%
timing 38.9%        moral-trial 35.0%         endure 32.6%
family-wealth 28.4% employ-person 25.7%       …其余 ≤20.1%
```

> 阈值是一个**判断**，不是自然常数。改动它必须重跑 `simulate_demotion.py`
> 与 `audit_skill.py`，确认 C1/C4/C5 与引用保真不退化。

## 扩充内核的方法

用户在描述里出现新的说法却匹配不到内核时：把该说法加进
`scenes.py` 的 `STEMS`（强）或 `EXTRA_STEMS`（复合词）。
判断标准：这个词是否**只**指向该类抉择？是 → 强碎片；
在任何决策语境都可能出现 → 弱碎片。
