## 打分（`retrieve.score_unit`，8 项）

| 项 | 权重上限 | 作用 |
|---|---|---|
| 古典信号词密度 | 5.0 | 该内核特有词的命中密度（非计数，避免长段占优） |
| 抉择证据词 | 3.0 | 判定「这是决策现场」而非背景叙述 |
| 选项对立结构 | 3.0 | 出现多方案争执（A曰/B曰/或曰/遂/卒） |
| 用户关键词 | 7.0 | 人名、事件等专有名词 |
| 白话译文 | 0.3 | 便于校准 |
| 后果信息 | 1.5 | 隐性代价分析的素材 |
| 长度归一 | ± | <60字扣 2.5；150-800字加 0.8 |
| **双向对话** | 1.6 | 既有进言、又有表态 = 真实决策记录 |

最终分 = 案例质量 × (0.55 + 1.45 × 场景权重)。

## 推演（`deduce.py`）

- `focus_span()` — **聚焦抉择现场**：整段可能含多个事件，
  以场景信号词为锚取 560 字窗口并对齐句边界，
  否则会抽到别的故事的发言（如核心是「乞骸骨」却抽到「谏猎」）
- `extract_choices()` — 引号深度计数找**所有**发言点；
  非「曰」标记（奏称/上言）也识别；
  极短主张（善/可/然/不可）标 `assent`/`dissent`，与 `propose` 分开
- `detect_decision()` — 采纳/拒绝/犹豫/原文未载
- `analyze_costs()` — 显性代价分层，**同时输出原句**（归属可能是
  相关方而非决策者，不替读者下结论）

## 代价词用词原则

宁取多字明确词，不取单字歧义词。反例：
- 「禽」常见于「驱禽除路」（鸟兽）→ 用「见禽」「禽获」
- 「罢」常见于「罢驽」（自谦庸劣）→ 用「罢官」「罢之」
- 「贫」常见于「民贫流亡」（描述他人）→ 用「府库空」「财尽」

## 已知边界

- 通鉴记大事不记细故；被否决的方案常已散佚 → 标「原文未载」
- 史记无白话译文（该库未提供），译文栏为空
- 事件单元窗口 4 段，可能仍含相邻事件的噪声 → 靠 `focus_span` 收敛
